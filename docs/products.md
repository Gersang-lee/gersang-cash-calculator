## 4. 계산기 설계 메모

- **입력**: 사용자가 필요한 아이템과 수량 → 최소 비용 조합 산출
- **비교**: 단일 상품만으로 채웠을 때 비용 vs 패키지 포함 최적 조합
- **변수 처리**: 단독가 없는 아이템은 사용자 입력 환산가를 사용하거나, 0원(덤) 취급 옵션 제공
- **잉여 처리**: 패키지 구매 시 남는 아이템을 "손실"로 볼지 "보너스"로 볼지 토글
- **정령 패키지**: 색상 5종은 가격/구성이 동일하므로 계산상 1종으로 묶고, 결과 표시 단계에서만 색상 선택
