# 거상 캐기 계산기

거상 캐시 이벤트 상품의 **현금 효율(1원당 지전)** 을 계산합니다.
`index.html` 파일 하나짜리라 브라우저로 그냥 열면 됩니다. 빌드도 설치도 없습니다.

## 쓰는 법

1. `index.html`을 브라우저로 연다
2. 아이템 지전 시세를 확인/수정한다 (기본값이 이미 채워져 있음)
3. 상품별 `1원당 지전`이 높은 순으로 정렬돼서 나온다

입력값은 브라우저 localStorage에만 저장됩니다. `기본 시세로 되돌리기`로 초기값 복원.

## 계산 방식

철희의 선물상자는 거의 모든 상품에 끼워져 있고 단독 판매가가 없어서, **공용 입력값으로 따로 분리**했습니다. 한 번만 정하면 24개 상품 전부에 같은 값이 적용됩니다.

```
총 지전   = Σ(구성 아이템 시세 × 수량) + 상자 개수 × 상자 시세
1원당 지전 = 총 지전 ÷ 상품 현금가
```

`상자 포함 / 상자 제외` 토글로 상자 값을 뺀 순수 아이템 기준 비율도 볼 수 있습니다.

## 데이터

- **상품 목록·현금가** — [docs/products.md](docs/products.md). 단일 15종 + 패키지 9종.
- **기본 시세** — 주작 서버 육의전 최저가 (2026-09-19 기준). 출처 [gerinee.com](https://gerinee.com/trade).
  코드 상단 `DEFAULT_PRICES`에 항목별 매물 수 주석과 함께 모여 있습니다.

시세는 수동 갱신입니다. gerinee.com API에 CORS 헤더가 없어 로컬 파일에서 직접 조회가 막혀 있습니다.
자동화하려면 스냅샷 스크립트나 프록시 서버가 따로 필요합니다.

### 손익분기선

캐시를 사통팔달에 직접 팔면 1원당 2.9만~3.0만 지전을 즉시 받습니다 (주작, 2026-09-19 오전 기준).
캐기는 이 선을 넘어야 의미가 있습니다.

## 주의

- 육의전 **최저가** 기준이라 실제 체결가와 다를 수 있습니다. 매물이 얇은 아이템은 특히 변동이 큽니다.
- 서버마다 시세가 다릅니다 (백호·주작·현무 등 13개).
- 환생의 서, 식객명부 용병은 주작 매물이 없어 기본값이 비어 있습니다. 해당 상품 2종은 회색으로 표시됩니다.
